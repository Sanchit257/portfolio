# Sanchit Kaushik — Portfolio

Personal portfolio site for Sanchit Kaushik.

**Live site:** [https://sanchitk.vercel.app/](https://sanchitk.vercel.app/)

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- React Bits (Waves background, TargetCursor)
